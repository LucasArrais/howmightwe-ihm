# Projeto React - Educação Financeira

## Como rodar

1. Instale Node.js
2. Abra o terminal na pasta
3. Rode:

npm install
npm start

## Estrutura

- src/components -> componentes reutilizáveis
- src/pages -> páginas
- src/styles -> estilos

## Objetivo

Projeto estruturado para portfólio UX/UI com base em pesquisa.
